## 📖 Week-by-Week Project Summary

### [Week 1: Superstore Retail Sales EDA](./Week-1-Superstore-EDA/)
- **Core Focus:** Cleaned and analyzed 5,009 sales transactions ($2.29M revenue, $286K profit, 12.47% margin).
- **Key Takeaways:** Consumer segment drives over 50% of revenue; severe profit degradation occurs when discounts exceed 20%; Technology is the highest-earning product category, while Furniture suffers from compressed margins.

### [Week 2: Power BI Executive Sales & Profit Dashboard](./Week-2-PowerBI-Sales-Dashboard/)
- **Core Focus:** Engineered a normalized Star Schema data model (`Fact_Orders` connected to `Dim_Customer`, `Dim_Product`, `Dim_Region`, `Dim_Date`).
- **Key Takeaways:** Built dynamic DAX measures (`Total Sales`, `Total Profit`, `Profit Margin %`, `AOV`), dynamic slicers, and interactive drill-downs across categories and regional territories.

### [Week 3: Customer Cohort & Churn Analytics](./Week-3-Customer-Cohort-Churn/)
- **Core Focus:** Evaluated customer churn on 7,043 telecom subscriptions (baseline churn 26.54%).
- **Key Takeaways:** Month-to-month contracts have a 42.71% churn rate compared to only 2.83% for two-year contracts; customers paying via electronic check experience 45.29% churn; Fiber Optic users lacking tech support exhibit a critical 49.37% churn risk.

### [Week 4: Corporate Financial & Margin Dashboard](./Week-4-Financial-Margin-Dashboard/)
- **Core Focus:** In-progress final internship capstone modeling corporate revenue, COGS, discounts, and operating margins with interactive scenario forecasting sliders.

## ⚡ Installation & Execution Guide

### 1. Clone the Repository
```bash
git clone https://github.com/Surya2006Jaya/Datheon_Data_Analytics_and_Power_BI_Internship.git
cd Datheon_Data_Analytics_and_Power_BI_Internship
```

### 2. Set Up Python Environment
It is recommended to use a virtual environment:
```bash
# Create virtual environment
python -m venv venv

# Activate environment (Windows PowerShell)
.\venv\Scripts\Activate.ps1

# Activate environment (Linux/macOS)
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Running the Jupyter Notebooks
To run Week 1 or Week 3 notebooks:
```bash
# Launch Jupyter
jupyter notebook

# Navigate to either:
# Week-1-Superstore-EDA/Superstore_EDA.ipynb
# Week-3-Customer-Cohort-Churn/Customer_Cohort_Churn.ipynb
```

### 5. Viewing the Power BI Dashboard
- Install **Microsoft Power BI Desktop**.
- Double-click `Week-2-PowerBI-Sales-Dashboard/Sales_Profit_Dashboard.pbix` to launch the interactive dashboard.
- Alternatively, review the pre-compiled executive PDF at `Week-2-PowerBI-Sales-Dashboard/reports/Sales_Profit_Executive_Report.pdf`.
