## 📌 Project Overview

This project will focus on developing an executive-level **Financial & Margin Performance Dashboard** using **Microsoft Power BI** and **DAX**. 

The primary objective is to monitor quarterly corporate revenue, Cost of Goods Sold (COGS), discount dynamics, and operating margins across corporate divisions and product segments to support executive financial decision-making and forecasting.

---

## 🎯 Planned Objectives

- Connect Power BI to the corporate financial dataset (Microsoft Financial Sample).
- Model an income statement hierarchy with gross-to-net waterfall revenue metrics.
- Analyze **Gross Sales**, **Discounts**, **Net Sales**, **COGS**, and **Operating Profit**.
- Perform actual-versus-budget variance analysis across fiscal quarters.
- Evaluate multi-currency / cross-regional corporate performance.
- Develop advanced DAX measures:
  - `Gross Profit Margin %`
  - `COGS Ratio %`
  - `Operating Segment Margin`
  - `Discount Impact Rate`
- Create dynamic scenario modeling sliders to forecast profitability under varying discount and cost conditions.
- Design an executive-ready financial KPI dashboard with high visual polish.

---

## 🛠️ Planned Tools & Technologies

- **Business Intelligence:** Microsoft Power BI Desktop
- **Data Modeling & Calculation:** DAX (Data Analysis Expressions), Power Query ETL
- **Techniques:** Financial Modeling, Variance Analysis, Waterfall Decomposition, Scenario Modeling
